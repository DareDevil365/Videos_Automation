# Create: current-affairs explainers

The `current_affairs` route turns a dated official-source brief into a portrait, narrated Short. Choose a broad topic a viewer can understand in one sitting. Lead with a specific implication, name the date and define one useful term. Show what changed and which qualification matters: direction, denominator, eligibility, exceptions or scope. Do not imply a new event occurred today merely because the source was checked today.

Use a factual `brief` or `brief_file`, a source-bound script, one narrator and exact script labels. The editor compiles original callouts/process graphics with measured speech and captions. No fake news screenshots, generated visuals or implied permission to reproduce a broadcaster's clip. The [source packet](../../../research/content-current-affairs/README.md) demonstrates the India–New Zealand FTA example and its primary sources. Country names and political figures are topics to research, not evidence.

Run the two [reviewed factual pilots](../../../tools/create_source_short_pilots.py) with `.venv\Scripts\python.exe tools/create_source_short_pilots.py`. The tool saves a local batch plan, runs the movie pilot first and then the current-affairs Short. Review facts again before any later publishing. This is not an activated daily news feed or posting automation.
