# Create: before/after rewrite reveal

Preset `rewrite_reveal`, education channel, 25–45 seconds, 65–115 spoken words and 6–12 units. It retains the accepted education voice and uses original graphics on every beat.

1. Prepare a factual brief/source excerpt supporting the communication technique. Introduce invented practice wording explicitly as a hypothetical instructional example; keep the factual brief/script labels truthful.
2. Choose one concrete weak phrase, explain the precise weakness, then speak and show the stronger version. Do not invent the viewer's experience, work results, income or hiring outcomes.
3. Create a new [playbook batch plan](../README.md#shared-playbook-batch-recipe) with `playbook: "rewrite_reveal"`, `channel: "education"`, your actual topic/source inputs and `test_only: true` for evaluation. New defaults enable graphics, hook alternatives, strict opening checks and separate editorial review; no lower panel is allowed and music is optional.
4. The director must put a supported graphic on every unit and include a comparison with exact existing weak/strong phrases and Before/After headings. Speak the improved wording, not merely the name of a framework. A comment question is optional and follows the answer.
5. Run/resume the plan using the shared commands, then inspect the whole video, wording, readable comparisons, speech, captions and review evidence.

See [editorial and speech contracts](../../EDITORIAL_AND_SPEECH.md), [writer rules](../../../Resources/Prompts/rewrite_reveal.writer.json) and the [offline demonstration tool](../../../tools/create_editorial_demo.py). The technical pilot is not audience/style approval. No external screenshot or named tool result is manufactured by this preset.
