# Yt Automation

**Yt Automation** is a personal tool that generates short-form videos and uploads them to its owner's own YouTube channel, then reads that channel's analytics to improve future content.

---

## Single User & Private Operation

Yt Automation is an internal, personal productivity application developed and operated solely for a **single user (the project owner)**. It is **not offered to the public**, does not provide commercial or multi-tenant services, and does not allow external user registration or third-party account connections.

---

## Google API Permissions & Purpose

Yt Automation integrates with the following Google OAuth scopes solely to manage the owner's personal YouTube channel:

* **`https://www.googleapis.com/auth/youtube.upload`** (`youtube.upload`):  
  Used exclusively to upload the owner's generated video files, set publication metadata (titles, descriptions, tags, and category), and configure visibility status.
* **`https://www.googleapis.com/auth/youtube.readonly`** (`youtube.readonly`):  
  Used to verify the owner's channel identity, inspect processing status of uploaded videos, and retrieve video details.
* **`https://www.googleapis.com/auth/yt-analytics.readonly`** (`yt-analytics.readonly`):  
  Used to fetch performance analytics (views, watch time, retention, likes, subscriber counts) strictly for the owner's own channel to inform editorial improvements for future video generation.
