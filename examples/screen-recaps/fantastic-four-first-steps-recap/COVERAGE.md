# First Steps coverage and continuity

Working choice: The Fantastic Four: First Steps (2025), Earth-828. This is not the 2005 origin, Rise of the Silver Surfer or the 2015 reboot. Source comparison is recorded in the brief; no full-film viewing is claimed. The source image is Disney’s streaming poster, not an original issue cover.

| Beats | Main cause, action or consequence |
| --- | --- |
| u1–u2 | The family/planet dilemma, established Four and Reed/Sue’s pregnancy. The actual title/poster identifies the adaptation. |
| u3–u4 | Surfer warning, space launch/world destruction, Galactus’s hunger and Franklin’s cosmic potential; refusing the bargain causes the chase. |
| u5 | Neutron-star escape and Franklin’s birth, shown as separate speech-anchored cuts. |
| u6 | Public pressure, Sue defending both humanity and her child, and Reed’s Earth-teleportation alternative. |
| u7–u8 | The destroyed global bridges, last surviving Times Square bridge, Johnny decoding Shalla-Bal’s past, victims’ recordings and her retreat. The remaining bridge changes the plan’s target. |
| u9 | Mole Man’s underground evacuation, Franklin bait, Galactus finding the real baby, stretched Reed and Ben’s rescue. |
| u10 | Reed retrieves the child; Sue’s force-field push, Johnny’s planned sacrifice and the herald’s actual intervention close the portal. |
| u11 | Sue’s death and Franklin’s revival supply the late payoff. |
| u12 | Four-year mid-credit jump, Doom beside Franklin and the unanswered purpose; then the subscribe line. |

Minor domestic exchanges and individual blows are compressed. No later Doom plan or unconfirmed sequel event is invented. The 1960s retro family world uses warm daylight/paper; space uses restrained violet and motivated star/portal light. Force-field contact, stretched limbs and a moving surfboard explain the action geometrically. This is a main-story short, not a replacement for the feature’s acting and full suspense.
