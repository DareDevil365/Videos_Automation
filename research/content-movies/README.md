The pilot answers a narrow viewer question: does the same actor establish the same Marvel character? After the audience pass, it also gives one optional movie for context: The Fantastic Four: First Steps. It connects the film primer to separately labelled comic lore, without claiming a comic episode is a film spoiler. The [official Disney+ guide](https://www.disneyplus.com/explore/articles/avengers-doomsday) directly addresses the unconfirmed connection. The [historical studio announcement](https://thewaltdisneycompany.com/news/marvel-studios-announces-robert-downey-jr-and-the-russo-brothers-to-return-for-avengers-doomsday/) documents casting, while [the current US title page](https://movies.disney.com/avengers-doomsday) supplies the current US release field. Historical announcements retain superseded dates; casting and date claims must not be refreshed indiscriminately from the same paragraph.

The backlog covers Doomsday, Secret Wars, Dune: Part Three, The Odyssey, Ramayana, watch recommendations, box-office updates, release hype and Hollywood discussion. Each entry records which region/status was actually verified. Exact UK Doomsday date sources conflict, so that date is not resolved here. No audience metrics, box-office record, celebrity-drama allegation or India streaming availability is supplied.

All visuals remain a separate rights/production decision. Original actor/character/theory comparison graphics can work without a copied poster or fabricated screenshot. The local test-only pilot uses measured voice and original pictograms with no visual-generation service, film download, provider key or upload. Audience interest remains unmeasured.
